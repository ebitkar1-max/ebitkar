# ابتكار للحلول الذكية — ebitkar.com

موقع تعريفي لشركة ابتكار، عربي/إنجليزي (RTL/LTR)، بتصميم مستوحى من kartogram.co.uk.

## الملفات

```
index.html            الصفحة الكاملة
css/style.css         كل التنسيقات
js/main.js            اللغة، المنيو، السلايدر، النموذج
img/                  اللوجو + خلفية الاسكتشات + صور الأعمال
server.js             سيرفر محلي للمعاينة فقط (غير مطلوب للنشر)
build-artifact.js     يجمّع الموقع في ملف HTML واحد للمشاركة
```

## المعاينة محلياً

```bash
node server.js
```
ثم افتح http://localhost:5173

## الرفع على الاستضافة (Hostinger)

ارفع محتويات المجلد كما هي إلى `public_html`، ما عدا `server.js` و `build-artifact.js` و `README.md` — الموقع HTML/CSS/JS ثابت ولا يحتاج أي إعدادات.

## ما يجب تعديله قبل النشر

| المكان | القيمة الحالية (مؤقتة) |
|---|---|
| رقم الهاتف | `+20 100 000 0000` — في `index.html` (‏`tel:` و `wa.me` والنصوص) |
| البريد | `info@ebitkar.com` |
| العنوان | القاهرة، مصر |
| روابط السوشيال | `href="#"` في الهيرو والفوتر |
| الأرقام | +120 مشروع، +80 عميل، +9 سنوات |
| الأعمال | 6 نماذج توضيحية في `img/work-*.svg` — استبدلها بصور مشاريع حقيقية |
| آراء العملاء | 3 آراء توضيحية |

## نموذج التواصل

يفتح حالياً برنامج البريد لدى الزائر (`mailto:`) بدون أي باك-إند.
لتحويله لإرسال فعلي: استبدل قسم رقم 6 في `js/main.js` بطلب إلى ملف PHP على الاستضافة أو خدمة مثل Formspree.
