# ابتكار للحلول الذكية — ebitkar.com

موقع تعريفي لشركة ابتكار، عربي/إنجليزي (RTL/LTR)، بتصميم مستوحى من kartogram.co.uk.

## الملفات

```
index.html            الصفحة الكاملة
css/style.css         كل التنسيقات
js/main.js            اللغة، المنيو، السلايدر، النموذج
img/                  اللوجو + خلفية الاسكتشات + صور الأعمال
server.js             سيرفر محلي للمعاينة فقط (غير مطلوب للنشر)
build-artifact.js     يجمّع الموقع في ملف HTML واحد للمشاركة
```

## المعاينة محلياً

```bash
node server.js
```
ثم افتح http://localhost:5173

## نموذج التواصل

يرسل فعلياً عبر SMTP إلى `info@ebitkar.com`، ويصل كرسالة منسّقة بهوية
الموقع. الرد على الرسالة يذهب للزائر مباشرة (`Reply-To`).

**كلمة السر:** موجودة في `mail-config.php` على الاستضافة فقط، وهو مستثنى
من Git فلن تجده في هذا المستودع. لو نُقل الموقع لاستضافة جديدة، انسخ
`mail-config.example.php` باسم `mail-config.php` وضع كلمة السر فيه.

**ملاحظة مهمة:** دالة `mail()` معطّلة على استضافة هوستنجر هذه — تُرجع
`false` دائماً رغم أنها غير مدرجة في `disable_functions`. لذلك SMTP
(‏`smtp.hostinger.com:465`) هو المسار الأساسي، و `mail()` مجرد خطة
بديلة لو انتقل الموقع لخادم يدعمها.

### الحماية

- حقل مخفي (honeypot) يوقع الروبوتات
- حد زمني 20 ثانية بين رسالتين من نفس الزائر
- تنظيف الأسطر الجديدة لمنع حقن ترويسات البريد
- تحقق من صيغة البريد، وحد أقصى 4000 حرف للرسالة
- `mail-config.php` و `smtp-send.php` محجوبان عن المتصفح عبر `.htaccess`

لو تعطّل الإرسال لأي سبب، يعود النموذج تلقائياً لفتح برنامج البريد لدى
الزائر — فلا يصل الزائر أبداً لطريق مسدود.
